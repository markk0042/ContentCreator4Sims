# Install: PS Flokati Rug

Base rug package used with permission from the original CC creator.

1. Download your new `.package` from SimForge Studio (file should be **about 4–6 MB**, not ~900 KB).
2. Copy **only** that file into `Documents\Electronic Arts\The Sims 4\Mods`.
3. Remove any older `rug_*.package` from Mods and remove the original **PS Flokati 2.package** if you still have it (two copies fight each other).
4. Enable **Custom Content** and **Script Mods Allowed** in Options → Other, then **quit to desktop** and relaunch.
5. In Build/Buy, search **Flokati** (not the download filename). Place the rug and try different color swatches.

**If the rug looks brown with tiny multicolor specks:** you have an old build that overwrote the normal map — re-download after the latest fix (only 512×512 swatches are replaced).

**If the rug looks unchanged:** light/white artwork on a pale rug can look like the default texture — try a version with a colored or transparent background, or pick a darker swatch in-game.

Keep the creator’s credit where their license requires it.
