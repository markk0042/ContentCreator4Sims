# Install: PS Flokati Rug

Base rug package used with permission from the original CC creator.

1. Download your new `.package` from SimForge Studio.
2. Copy it to `Documents\Electronic Arts\The Sims 4\Mods`.
3. Enable **Custom Content** in Options → Other, then restart the game.
4. In Build/Buy, search for the rug name from the original mod (Flokati / creator’s catalog name).

Your upload replaces all color swatches in this base. Keep the creator’s credit in your project README or site if their license requires it.
