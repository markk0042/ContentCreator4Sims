# Install: Wall Art / Poster

1. Download your `.package` file from ContentCreator4Sims.
2. Open File Explorer and go to:
   `Documents\Electronic Arts\The Sims 4\Mods`
   (Create the `Mods` folder if it does not exist.)
3. Copy the `.package` file into `Mods`.
4. Enable **Script Mods Allowed** and **Custom Content Enabled** in The Sims 4:
   - Main Menu → Options → Game Options → Other
5. Restart the game completely (quit to desktop, then relaunch).
6. Find the item in Build/Buy or on your Sim, depending on the base template.

> **Note:** Dev template packages contain texture resources only. For in-game objects, replace base packages with exports from Sims 4 Studio (see `docs/STUDIO_TEMPLATES.md`).
