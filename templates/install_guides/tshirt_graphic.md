# Install: T-Shirt Graphic

1. Download your `.package` file.
2. Copy to `Documents\Electronic Arts\The Sims 4\Mods`.
3. Enable CC in Options → Other, then restart the game.
4. Open CAS and look for the clothing item tied to your base template.

Replace the dev base package with a Sims 4 Studio clothing recolor base for real CAS items.
